## 4. The nine verification questions

**1. Can Shashank understand and use every processed dataset without asking about grain?**
Yes. `DATA_HANDOVER.md` opens with a grain table for all four files; `DASHBOARD_DATA_HANDOVER.md` §B
restates it with the arithmetic (18,060 → 15,727, the 1,067 multi-country events, the 14.8% inflation

`ISO`); `Event ID`). Both are backed by executable checks (`I-disno-unique`,
`I-event-country-unique`, `E-unique`, `Y-grain`).

**2. Can he reproduce the preparation and the validation?**
Yes, and this was proven rather than asserted: `prepare_emdat.py` run against a fresh copy of the
workbook in `/tmp/repro` produced **byte-identical** output for all four CSVs. Validation
(`validate_project_data.py`, standard library only) and verification (`verify_eda_findings.py`) both
exit 0 with the documented counts. Known environment caveat: in this sandbox
`python -m pip install -r requirements.txt` fails with a virtualenv permissions error, so `openpyxl`
was installed to a temporary path; on a normal machine the README command works and the two
source-workbook checks report PASS instead of SKIP.

**3. Are all columns, derived fields, units, aggregation rules and missing-value limitations
documented?**
Yes — after this audit. `DATA_DICTIONARY.md` lists every column of all four files with origin
(EM-DAT vs derived), type, unit/domain, nonblank count and rate, and notes; §1 closes with the six
derived fields named explicitly; §5.1 is an additivity matrix (what may and may not be summed); §5.3
is a unit table; §5.4 lists the nuances. Missingness is stated at both grains in
`DATA_QUALITY_REPORT.md` §4 and enforced by `M-no-zero-fill`. Before this audit, 22 of the 53 impact
columns were undocumented.

**4. Can Shreya Patil build the analytical dashboard without more data preparation?**
Yes. She needs no new files and no new columns beyond one computed flag. `DASHBOARD_DATA_HANDOVER.md`
§G.1 gives the load settings, §G.2 the model with the bridge table, §G.3 the measures written against
column names verified in the CSVs, §E the four pages, §F the interactions, and §C the totals her
measures must reproduce (15,727 events; 32,842,715 deaths; 9,065,006,097 affected;
8,120,533.17 million US$; coverage 74.1 / 78.6 / 33.4%). The country join is `ISO`, which is 1:1 with
230 country names (verified).

**5. Are the Power BI aggregation and double-counting pitfalls explicit?**
