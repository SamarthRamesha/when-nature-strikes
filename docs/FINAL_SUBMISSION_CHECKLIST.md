# Final submission checklist

- Review the report and deck with the project team. Apply any institution-specific
  front matter, templates or submission rules when provided.
- Confirm the contributions and applicable AI disclosure with each member
  and the institution.
- Rehearse the [dashboard demo](../submission/dashboard_demo_guide.md) using
  the authorized workbook on the demo machine.
- If a native PBIX is mandatory, build and validate it using the
  [Power BI sources](../dashboard/powerbi/README.md) in Power BI Desktop for Windows.
- Verify any needed permissions for sharing the custom workbook or an imported
  PBIX with an evaluator. Use provider access for the source.
- Review the implementation PR. A merge into main requires explicit owner approval.
- Submit the [package](../submission/README.md) through the institution's process
  after review and sign-off.
